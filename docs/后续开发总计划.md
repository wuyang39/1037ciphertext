## 2. 最终完成定义

只有同时满足以下条件，项目才可标记为完成：

1. 一台真实 SGX/vSGX 实例产生有效非 debug Quote，KAS 完成验证并签发短期身份和 Lease。
2. 修改受测量文件、使用 debug enclave、重放 challenge 和替换临时公钥均被拒绝。
3. Gramine encrypted FS 由 KAS 放行的磁盘密钥挂载，宿主直接读取无法获得模型份额。
4. P0/P1/P2 在三个 enclave 内通过真实 mTLS/BRPC 通信，关闭 TLS 时 fail-closed。
5. Tiny Decoder、完整 Transformer Block 和正式中文 GPT-2 级模型完成真实私有推理。
6. 连续生成至少 2 token，ResultFrame、Ticket、session、epoch 和模型绑定负例全部拒绝。
7. 性能报告包含同条件开/关对照、token 一致率、误差、延迟、通信量、内存和安全回归。
8. 从干净环境按安装手册完成一次三节点部署和离线复现。
9. 所有对外结论均能对应代码、配置、日志、Quote、pcap、trace 或证据 hash。
10. 云实例、云盘、EIP、快照、镜像和带宽均完成计费核对与释放。

## 7. D4：真实三节点 enclave 通信与 3PC RSS

### 目标

用 YACL/BRPC 和真实证书替换 mock mTLS，在三个 enclave 内完成最小算子。

### 前置条件

- D1 单机验收通过。
- D3 单节点 encrypted FS 验收通过。
- 模型份额、证书和 KAS 密钥边界已经固定。

### 资源

- 三台 `ecs.g7t.2xlarge`。
- 同地域、同 VPC，优先同可用区。
- P0/P1/P2 使用独立安全组或至少独立审计标签。
- 节点间只开放协议所需私网端口。

### 执行项

1. 将 `mpc/spu_backend/mtls.py` 的 mock channel 替换为 RA-TLS + YACL/BRPC。
2. 为 P0/P1/P2 绑定 KAS 签发证书，校验 CA、SAN、角色和 Lease。
3. 在 enclave 内建立 TLS 1.3 通道，禁止 builtin services 和明文回退。
4. 启动三节点 SPU topology，执行 add、mul、matmul、truncate、compare、reciprocal。
5. 在三个 enclave 内运行至少 1,000 组确定性和边界向量。
6. 抓取 pcap，确认协议流量只包含 TLS records。
7. 执行明文端口、错误 CA、错误 SAN、无客户端证书和 TLS 关闭测试。
8. 将通信 trace 和材料消费记录写入统一证据目录。

### 代码改造点

- `mpc/spu_backend/mtls.py`：替换 mock policy，接入真实 TLS channel。
- `mpc/spu_backend/topology.py`：绑定真实节点证书、角色和地址。
- `mpc/secure_ops/rss.py`：由确定性模拟器迁移到真实 SPU/YACL 后端。
- `mpc/material_ledger/ledger.py`：验证跨节点材料一次性消费。
- `infra/`：新增三节点安全组、证书分发、启动和 pcap 脚本。

```text
├── p2-cert.pem

```

### 验收门

## 8. D5：私有 Tiny Decoder Transformer Block

### 目标

在三个 enclave 内完成两轮 Tiny Decoder Block，并替换所有 simulation reveal。

### 执行项

1. 运行 secure embedding、QKV、causal attention、Softmax、A*V、残差、LayerNorm、FFN、GELU 和 Argmax。
2. 用真实 secure nonlinear operator 替换生产路径中的 simulation reveal。
3. 对每个算子和每层记录 `max_abs_error`、`mean_abs_error`、`relative_error`、`overflow_count` 和 `argmax_match`。
4. 对 Softmax、Norm 和 GELU 先跑合成边界，再跑 block，最后跑 Prompt 集。
5. 记录每个非线性算子的 enclave 内通信 profile。
6. 扫描代码，确认生产路径不存在 `reveal()`。

### 代码改造点

- `mpc/secure_ops/transformer.py`：替换 reveal 路径，接入真实 secure operator。
- `mpc/secure_ops/approximations.py`：按 precision plan 应用 clip、scale 和迭代次数。
- `mpc/secure_ops/fixed_point_adapter.py`：确认真实后端与本地参考一致。
- `benchmark/collector.py`：增加 per-operator profile 字段。

### 验收证据

- 三个 enclave 的节点启动和证明日志。
- 每层、每算子误差表。
- 溢出统计与 argmax 一致率。
- per-operator 通信量与延迟 trace。
- 生产路径 `reveal()` 扫描结果。

### 验收门

完整 Block 在三节点 enclave 内运行；所有误差在登记阈值内；不存在未解释溢出或生产 reveal。

6. 从一台新机器按安装手册部署客户端并完成端到端推理。
7. 完成一次离线复现和 15 分钟答辩演练。
8. 保存所有证据 hash，记录实例、镜像和网络配置。

### 代码改造点

- 新增 `deploy/` 下的创建、配置、启动、健康检查、演示和释放脚本。
- 新增 release manifest 校验器，拒绝 hash 不一致的包。
- 将 KAS/Audit 从 SGX 节点镜像中拆出。
- 为每个负例输出统一 JSON 证据和审计关联 ID。

### 验收证据

- 六类攻击负例的请求、拒绝点和审计记录。

## 15. 成本控制

### 参考单价

以下仅为 2026-10-09 购买页参考，实际价格以当天下单页为准：

| 规格 | 参考实例单价 |
| --- | ---: |
| `ecs.g7t.xlarge` | 约 ¥1.2075/时 |
| `ecs.g7t.2xlarge` | 约 ¥2.415/时 |

加入 100 GiB ESSD PL1 后，单台 `ecs.g7t.xlarge` 结算页曾显示约 ¥1.4175/时。三台 `ecs.g7t.2xlarge` 的实例费用约为 ¥7.245/时，另加云盘、流量、快照和镜像费用。

### 预算阶段

1. D1：只租一台 `g7t.xlarge`，目标是半天内完成。
2. D3：优先复用 D1 的镜像和实例，不提前扩到三台。
3. D4-D8：仅在三节点任务连续执行期间租三台 `g7t.2xlarge`。
4. D9：使用正式部署包创建短时三节点环境。
5. 每个阶段结束立即保存证据、日志和镜像，再释放实例。

### 费用停止条件

- 单次调试超过 30 分钟无进展时，停止实例或记录状态后释放。
- 连续两次健康检查失败且原因无法在 15 分钟内定位时，停止环境并回到本地修复。
- 最终演示完成后立即释放，不使用“节省停机”代替正式清理。
- 释放后必须检查云盘、EIP、快照、镜像和带宽。

## 16. 失败处置

| 现象 | 处置 | 禁止 |
| --- | --- | --- |
| 阿里云风控未解除 | 联系客服，等待处理后再采购 | 绕过风控或重复刷单 |
| 上海无库存 | 依次检查杭州、北京、张家口等候选地域 | 三节点拆到不同地域 |
| `g7t` 无库存 | 评估 `c7t`、`r7t`，重新验证 SGX 能力 | 假设 6 代规格支持 SGX |
| CPUID 无 SGX | 更换地域、可用区或实例族 | 使用 Mock Quote 继续 D3 |
| Gramine 无法启动 | 缩小入口和依赖，先跑 Hello Enclave | 在未证明环境加载份额 |
| encrypted FS 失败 | 回到 D3 修复 key、epoch、manifest 和 Lease | 把明文模型放入宿主 |
| YACL/BRPC 不通 | 先做 Echo/add/mul，再定位 Link 和证书 | 使用 host 外 TLS 终止 |
| SPU 不支持算子 | 用固定长度图或安全近似重写 | 回退到客户端明文回调 |
| Softmax/Norm 溢出 | 修 clip、scale、固定点和迭代 | 放宽阈值掩盖错误 |
| 模型内存超预算 | 缩短上下文、生成数和层数 | 删除真实证明或 mTLS |
| 成本失控 | 立即保存证据并释放资源 | 保留空转实例等待决定 |

## 19. 完成判定规则

- 代码存在不等于阶段完成。
- 本地 mock 通过不等于真实服务器验收。
- 单个 Quote 存在不等于 KAS 验证闭环。
- 三节点能启动不等于 enclave 内 mTLS 和 secrets 边界正确。
- 模型能输出文本不等于私有 RSS 路径完整。
- benchmark 表格存在不等于数据可复现。
- 只有“实现、运行、拒绝负例、保存证据、可离线复现”五项同时满足，阶段才可标记完成。
